# BoE_Mpr

Plataforma de planificación y suministro para empresas que entregan productos o servicios.

## Estructura

- `backend/` — API y lógica de negocio (Python + FastAPI)
- `frontend/` — Interfaz de usuario (React + TypeScript)
- `docs/` — Documentación del proyecto
- `.github/` — CI/CD

## Requisitos

- Docker Desktop
- Python 3.12
- Node.js 22
- uv
